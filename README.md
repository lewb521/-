# 不白背 · BuBaiBei

**免费开源的英语词汇学习 PWA：分阶段词库、虚拟键盘拼写复习、查漏补缺，无广告、无注册，打开即用。**

## 🚀 在线预览

### 👉 https://lewb521.github.io/-/

手机浏览器打开即可学习；支持「添加到主屏幕」，以独立 App 形态离线使用（PWA）。

## ✨ 功能特性

### 📚 学习
- **分阶段词库**：中考 1,600 / 高考 3,674 / 四级 3,846 / 六级 5,406 / 考研 4,801，合计 **19,327** 词条（按语料库词频从常用到生僻排序）
- **复习只考拼写**：给出中文释义与词性，用自建虚拟键盘逐字母输入英文后提交，没有选择题、没有连线
- **虚拟键盘防联想**：不唤起系统输入法，键盘只有 a–z 和连字符，杜绝候选词提示
- **答完即判**：答对画粗体对勾并自动进入下一题；答错或点「不会」显示正确答案，错词自动收进查漏补缺
- **标准手机键盘排布**：字母键帽大写、输入框内保持小写；shift 与底行多余键位为空白占位，提交键放在回车位
- **英音 / 美音发音**：单词页两个小喇叭，「前进」切换单词时自动先播英音、播完接美音；音源优先有道，失败自动回退系统 TTS
- **前进 / 复习双入口**：前进学习新词、复习巩固旧词，学习阶段随时切换
- **查漏补缺**：个人页进入，分「温故」（像前进页一样逐个重温已学单词）与「补缺」（复习时答错 / 不会的错词本，可重拼、可标记已掌握）
- **单词浏览**：「前进」「温故」均可逐个翻阅，随时回溯上一个

### 🎞 动效系统

- **统一视效**：时长与缓动收敛为一套设计 token（CSS 变量 + JS 常量），页面切换、单词切换、弹窗、导航、按钮按压、Toast 全部复用同一节奏
- **高斯模糊切换**：主页三页切换约 480ms（旧页散焦 → 新页聚焦）；单词切换为「当前词虚化 → 就地换词 → 由模糊变清晰」
- **入场过渡**：「前进 / 复习」大圆角卡片点击后，从按钮位置放大为全屏蒙版，主页内容反向（上移 + 缩小 + 淡出）消失，内里内容自上方错峰滑入
- **导航吸附**：个人页 / 设置页向下滚动时，贴近底部悬浮导航的内容会渐进高斯模糊并轻微缩小下沉，像被导航「吸」过去
- **键盘动效**：输入框空着时是一个短短的圆角小框，每打一个字母向外扩张；字母向上蹦出并带高斯模糊，删除同样飞出；换题时输入框向内缩回、题目文字模糊上飞，提交后 0.5s 描出粗体对勾或叉
- **无障碍降级**：系统开启「减少动态效果」时自动切换为瞬时状态，不做模糊 / 形变

### 📊 学习数据
- **当前阶段背诵进度**：粗体进度条 + 百分比 + 已背 / 本阶段词库总量
- **当日学习时间饼图**：环形图展示「前进 / 复习」两段时间占比，中心显示今日总时长
- 今日学习、历史学习、学习天数一目了然

### 🔤 字体
- 拼写答题的字母使用 **阿里巴巴普惠体**（仅内嵌 A–Z 子集，约 3 KB，随页面离线可用）

### 🎨 个性化与离线
- 深色模式、昵称、头像
- 设置 → 关于：开发者署名 **灵力开发**、词汇数据来源、在线预览与源码入口
- 纯前端实现：无注册、无广告、无服务器；数据只保存在本地 `localStorage`
- PWA：可添加到手机桌面，离线可用

## 🕹 使用方法

### 在线使用
直接访问 **https://lewb521.github.io/-/** 即可。

### 本地使用
下载仓库后直接打开 `index.html`；或起一个静态服务器（PWA、字体等行为更接近线上）：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 安装到手机桌面
- **iOS Safari**：分享 → 添加到主屏幕
- **Android Chrome**：菜单 → 安装应用 / 添加到主屏幕

## 🗂 目录结构

```
.
├── index.html        # 应用本体（结构 + 样式 + 逻辑，单文件）
├── words-data.js     # 词库数据（由脚本生成）
├── tools/
│   └── build_words.py  # 词库生成脚本
├── vocabulary/       # 词库源 JSON（放 中考/高考/四级/六级/考研 五个文件）
├── appIcon.png       # 应用图标
├── manifest.json     # PWA 清单
└── README.md
```

## 🧠 数据说明

- 学习数据保存在浏览器 `localStorage` 的 `bcz_data` 键中，包含：学习阶段、已学单词与时间戳、每日学习量、每日学习时长、主题、昵称头像。
- 清除浏览器站点数据 / 卸载 PWA 会同时清除学习记录；重置入口在「个人页 → 数据 → 重置所有数据」。
- 学习时长从 v2.1 起开始统计，仅累计「前进 / 复习」页面的停留时间，历史时长不补录。

## 🔧 技术栈

- 原生 HTML / CSS / JavaScript，**单文件应用、零构建步骤**
- SVG 环形图、CSS 变量动效系统、滚动位置驱动的吸附模糊
- PWA（manifest + 离线可用）、`localStorage` 本地存储
- 无任何第三方运行时依赖

## 📚 词库来源

- 词汇数据来自 **英语词汇大纲**（中考 / 高考 / 四级 / 六级 / 考研五份 JSON，词条含音标、词性、释义、词频、柯林斯星级）
- 原始词条出处：[ECDICT](https://github.com/skywind3000/ECDICT)（MIT License）
- 生成方式：把五份 JSON 放进 `vocabulary/`，执行 `python3 tools/build_words.py` 重新生成 `words-data.js`
