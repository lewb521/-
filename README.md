# 不白背

一款免费开源的英语词汇学习 PWA，专为碎片化记忆设计。无广告、无注册，打开即用。

## 功能

- 分阶段词库：中考 / 高考 / 四级 / 六级 / 考研
- 四种题型：拼写、中英选择、连线匹配，随机轮换
- 智能复习：优先巩固已学单词
- 每日目标与连续打卡
- 深色模式 + 离线可用（PWA）

## 使用

直接在浏览器打开 `index.html` 即可开始学习，支持添加到手机桌面。
